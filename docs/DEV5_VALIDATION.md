# dev.5：离线标点、句末音频复核与输入设备选择

## 实现

保留 dev.3/4 的 Zipformer 小型双语流式模型、4 路束搜索、自适应停顿和默认 5 秒连续讲话预算；Vosk 兼容模式同样保留预算。没有更换为先前效果较差的 SenseVoice/Silero 分段主识别方案。

新增两个离线模型：SenseVoice INT8 对刚结算的整段音频进行复核，CT Transformer INT8 恢复标点。两种尾部静音条件下的复核归一化结果必须一致，才可追加一个带来源标记的字母候选；没有变化或不符合条件时只跑一次。该稳定性检查不是独立模型投票，也不能证明输出必然正确。模型不接收危险词列表，无针对 qaq / P老板 的分支或汉字谐音补丁。原始首候选保留。

服务端区分原始与复核候选：复核只允许至少两个字符、含 ASCII 字母的危险词按**精确包含**触发（例如 amc 可包含 mc，符合当前游戏规则）；混合词里的中文部分还必须已存在于原始首候选。复核不走谐音、编辑距离或跨段拼接，纯中文及单字不能因复核而处罚。原始候选仍走既有匹配。标点必须通过正文一致性校验，仅用于展示，不作为语音端点或处罚正文。

句末模型后台准备，下载/加载失败时继续基础识别；两项均关闭即可恢复 dev.4 基础链路。缓存共约 315MB，清单固定版本与 SHA256，模型不随 JAR 打包。后台加载中停止会话会中断准备，并释放迟到的模型。相同缓存目录准备串行进行。

Windows / macOS 均可按 F8 选设备或使用网页下拉框「连接并保存」；连接成功才保存。F8 长设备名称有完整提示，网页标识已保存但已不可用的设备，显示句末模型状态、最近标点文本及耗时。真实物理设备和游戏内界面尚未实测。

客户端与服务端须同时更新到 dev.5。新服务端兼容旧纯文本/v2 原始候选；带复核来源扩展的包会被旧服务端拒绝，避免旧匹配器把复核候选当成普通备用候选。

## 验证方式

48 项 JUnit 测试覆盖候选来源、精确包含、中文依据、复核不跨段、标点正文保护、复核不一致、异步退出、录音生命周期、PCM 转换与 20 词 HUD 编解码。构建使用 `test build -x deployToGame`，没有部署游戏。

原组 22 段（17 种独立波形）、额外 14 段近邻负例、49 条中文音色 SSML 字母拼读记录（33 种独立波形）以及连续讲话/空闲控制，均沿用已有 WAV 并逐文件校验 SHA256。每组最终实时复测一轮；专项另跑相同词表的基础识别对照。重复合成音不代表独立口音或真人准确率。

延迟是 PCM 文件按实时节奏输入后，估算语音结束到本地匹配命中的墙钟时间；不包含模型初始化、真实驱动、游戏 tick 和网络。RMS 语音边界为机器估算。实时回放与其他推理、编译串行执行。原始识别结果等待句末处理后一起发送，因此复核会增加延迟，不能宣称整体更快。

## 已知限制

原组 TTS 直接读字符串 qaq 的三种登记音色仍漏判，中文拟音也未保证触发；逐字母 SSML 组用于明确区分字母朗读和汉字谐音。B站的中文部分识别错误时，安全约束会保留漏判。纯中文整句联想改写尚未实现，当前是有音频依据的句末复核。MC 的复核转写 amc 可按包含规则补回命中，但不等于逐字母完全识别正确。专项基础识别已知的 MC → ABC 误转写/误触发没有解决；不能将五词回放的零误触发外推为全词库零误杀。

5 秒是首次出现识别假设后的输入音频预算，还会叠加首词识别、模型分块、复核推理和网络/游戏耗时；不能承诺开口 5 秒内必定处罚。模型后台准备期间只使用基础结果。未知设备、真人口音、噪声、长会话负载、切换设备和联机需实测。当前没有 Windows/macOS 物理麦克风验收证据。

## 复现入口

`replayNicknames` 使用实际 CaptureSession → Decoder → SpeechPacket → SpeechWindow。`-PreplayEngine=enhanced` 启用实际句末模型；所有模型使用单 CPU 线程，复核/标点模型在整个测试进程共用，避免逐文件重复加载。各段匹配历史独立、原始样本标签只用于计分，不传给复核模型。

运行 enhanced 回放前，需按生产清单预先安装模型：复核文件放在本仓库 `.local/models/sensevoice-int8/`，标点文件放在 `.local/models/punctuation-int8/`；回放入口会校验两者的大小和 SHA256。游戏使用配置指定的缓存目录，目录名与测试缓存不同。

```powershell
.\gradlew.bat test build -x deployToGame
.\gradlew.bat replayNicknames -x deployToGame '-PreplayEngine=enhanced' '-PreplayRounds=1' '-PreplayOutput=.local/diagnostics/dev5/original.json'
python tools/summarize-dev5-validation.py
```

模型目录、原语料准备与其他回放参数见 [模型说明](ASR_MODELS.md) 和 [回放文档](NICKNAME_REPLAY.md)。本地证据存于 `.local/diagnostics/dev5/`；不提交音频、模型、机器配置或构建产物。

# dev.14 物品栏提示背景宽度

截图中的五个词已在一行显示完，但黑色背景仍占据整段配置宽度。原因是 `HudOverlay.drawHotbar` 同时把 `hudHotbarWidth` 用作换行宽度、背景宽度和居中依据；短内容因此左偏且尾部留有大段空白。

现在先按最大宽度换行/分页，再用 Minecraft 字体测量当前页的实际最宽文字，计入页码宽度后绘制背景，两侧各留 6 个 GUI 像素，整块居中。长提示的换行、分页、展示时间、距底部距离和颜色保持原逻辑。F7 标签改为“物品栏提示最大宽度”，现有配置无需调整。

仅客户端显示代码改变，服务端可继续使用 dev.13；语音识别、读音匹配、模型及词库没有改动。客户端候选版本 1.0.15-dev.14。

验证：`./gradlew.bat test --tests com.example.voicekill.client.HudBehaviorTest build -x deployToGame`。5 项现有 HUD 回归通过，remapped JAR 构建成功；不重跑不变的语音模型/104 条音频。未启动 Minecraft 目视验收，未部署到玩家实例。dev.13 的 132 项全量回归记录保留在原验证文档。

完整离线包仍为四模组、四组模型共九个模型文件，不含 Vosk，模板关闭回退/自动下载；模型与用户 WordBank 保持原样，原安装教程只追加本次兼容说明。

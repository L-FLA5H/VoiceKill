# VoiceKill (言多必失 Mod) 傻瓜式安装指南

**适用版本**：Minecraft Java **1.21.11** | **Fabric**（最低 0.17.3，本包已核对 0.20.0）| **Java 21**
*(注：本压缩包只含 Mod 和离线语音模型，不含游戏本体和启动器)*

---

## 一、三步安装法（装前先关游戏！）

先在启动器（如 PCL2）里打开当前版本的**游戏根目录**：

> 如果你开了版本隔离，路径一般长这样：`...\.minecraft\versions\1.21.11-Fabric 0.20.0`

**第 1 步：塞入 Mod**

* **老玩家更新**：先把游戏 `mods` 文件夹里旧版的 `voicekill-*.jar` 删掉或移走备份。
* 把压缩包 `.minecraft/mods` 里的 **4 个 jar 文件**全部拖进你的游戏 `mods` 文件夹。*(如果本来就有 Fabric API 等前置，同一模组只保留一份适配 Minecraft 1.21.11、满足依赖要求的版本，别重复放；不要只看版本号高低。)*

**第 2 步：塞入离线语音模型（免下载直接用）**

* 把压缩包 `.minecraft` 里的 **`voicekill` 整个文件夹**，直接拖进你的**游戏根目录**。
* **防呆检查**：放好后的路径应该是 `<游戏目录>/voicekill/models/...`，**版本隔离时不要**在版本目录里再套一层 `.minecraft`！包里的 `.minecraft` 是内容容器，应把其内部内容放入启动器显示的实际游戏目录。
* *(如果是之前已装齐本项目 dev.5/dev.6 三组模型的老玩家，只需补上 `<游戏目录>/voicekill/models/silero-vad/silero_vad.onnx`；原有模型缺失或损坏时，仍需从完整包补齐。)*

**第 3 步：放入配置文件**

* **纯新手（第一次装）**：把压缩包 `config-template` 里的 `voicekill.json`，拖进 `<游戏目录>/config/` 文件夹里；没有 `config` 文件夹就先新建。
* **老玩家（升级）**：**千万别覆盖这个文件！** 否则你以前辛辛苦苦配好的违禁词、朋友外号、麦克风设置全没了。

**客户端与服务端都更新到 dev.16，进入游戏就监测：最终句按读音向危险词匹配，正常受伤摇晃保留，静默扣血无随机击退或虚构方向。** 单人世界重启游戏加载新版即可，原模型和配置继续使用。读音匹配默认开启、强度 0.30；可在单人 F7 →「游戏与词库」或服主网页调整，越大越宽。

dev.15 将左上危险词、字幕和物品栏提示背景都改为按实际文字宽度自适应，此次同时新增麦克风/模型故障保护，完整入服检查需要双方dev.16。原配置中的宽度作为换行上限；左上两块保持左对齐，物品栏提示居中，无需调整配置。

dev.16进入世界/服务器后就检查麦克风和模型，`/vk start`不会重置已确认状态；未确认约4秒或异常持续约2秒才弹提醒，未开始玩法不会扣血。单人更新客户端JAR即可，联机请服主更新服务端。

## 二、进游戏必调设置（老玩家升级也看这里）

1. 启动游戏，按 **F8** 选择你正在用的麦克风。
2. 按 **F7** 打开 Mod 主设置，照着下面检查（**老玩家升级不会自动改已有数值，必须手动调一下**）：
   * **设备与模型 → 识别引擎**：选 `Zipformer`（本包自带离线模型，不用联网下载）。
   * **语音识别 → 声学自然断句**：开启。
   * **停顿确认**：改成 `0.6` 秒左右。
   * **持续讲话兜底上限**：改成 `10` 秒左右。
3. 改完直接点 F7 底部的 **“保存并重连麦克风”**。F8 没有单独的“重连”按钮；想从 F8 重连，重新选择正在用的设备即可。

模板已关闭自动下载和 Vosk 回退，**包里不带 Vosk 模型**。若自行开启自动下载，可在 **F7 → 设备与模型 → 模型下载进度**查看下载与校验状态。

## 三、怎么开始玩 & 新版功能

* **可选的无识别文字扣血**：默认关闭。单人按 F7 →「游戏与词库」开启；联机由服主在网页控制台设置。默认 20 秒没有新识别文字开始每 4 秒扣 1 颗心，等待时间、扣血量、间隔都可调。实时转写更新或最终识别会重置等待，只有麦克风音量不算。保存后立即生效，无需重连。麦克风/启用的模型未就绪或出现故障时暂停判定和此项扣血，底部每约10秒提醒；恢复后重新等待。已有配置不会被覆盖，需手动将读音强度/等待/间隔设为0.30/20秒/4秒。

* **开关游戏**：进存档或服务器后，公屏输入 `/vk start` 开始处刑，输入 `/vk stop` 停战。平时不想录音也可以按 **F8 → 停止录音**。（第一次进游戏加载语音模型需要等待，可以在 F8 里看状态。）
* **全新整活死亡播报**：这一版默认开启了 `friends`（损友整活）模式，内置 20 条损人死亡文案。你可以在 **F7 → 游戏与词库 → 自定义死亡文本**切换经典模式、其他主题，或者自己写文案。**注意：改完文案后要先点“应用到设置草稿”，退回上一页再点“保存”才生效。** 死亡时仍保留玩家名、危险词和识别原文公告。
* **临时字幕不直接处罚**：屏幕上有实时字幕，字面出现的危险词会标成粉红色。临时文字不会直接弄死你，等自然停顿或达到持续讲话兜底、系统输出最终结果后才会判定。**粉红色只是显示提示，不代表绝对不会误杀。**
* **界面自己调**：F7 可调字幕、危险词与物品栏提示换行、言多必失榜的位置；布局预览使用示例数据，不会处罚玩家。

## 四、朋友联机 & 开服须知

* **客户端（所有要开麦玩的玩家）**：按上面“三步法”完整安装，Mod + 模型都得装。每个人在自己电脑上按 F7 / F8 调自己的麦克风和界面位置。
* **服务端（腐竹/开服的人）**：服务器只需要放那 **4 个 Mod（jar）**，**不需要放语音模型文件夹**。词库、玩家外号、死亡文案风格全由服主统一控制。
* 服务端网页后台只能在服务器本机用 `http://127.0.0.1:38471/` 打开，玩家在自己电脑上打开这个地址，访问不到远程服务器的后台。单人世界或自己电脑开服时，可以在本机使用。

### 已知小毛病（不用大惊小怪）

* **说话别大喘气**：断句靠声音停顿判断，你停顿太久，或者一口气连说超过约 10 秒，系统还是会帮你断句；解码和网络耗时另计。
* **谐音梗与口音**：英文缩写和部分读法仍有漏判或误判，例如把 “MC” 听成 “ABC”、个别 “P老板” 没认出来。别把它当作零误杀系统。
* **实机验收还在继续**：合成音频回放和自动测试通过，不代表所有真人口音、JBL/macOS 麦克风或多人联机都已验证；最新模型进度页、死亡编辑页和实际死亡效果仍待进一步游戏内实测。
* **开发者备忘**：查文件完整性或底层参数，翻包里的 `设置详解.md`、`验证记录.md`、`manifest.json` 和 `SHA256SUMS.txt` 即可，普通玩家照上面安装就行。
